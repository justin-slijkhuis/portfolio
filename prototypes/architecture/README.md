# Architecture prototype

This is a simple prototype to test the architecture. This prototype does not focus on quality, but is instead quickly put together to test the ideas for the posts section and validate some assumptions that were made.

To read more about this prototype, then please visit the [prototype architecture documentation](https://github.com/justin-slijkhuis/portfolio/wiki/4.-Architecture-Prototype). This will describe what this prototype is for and what was achieved by building it. Again, this prototype is not meant to be a final product or even a product at all, but is instead a way to test the ideas for the posts section.
